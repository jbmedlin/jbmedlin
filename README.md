# J. B. Medlin

Indie game developer and author. I make sci-fi horror games and write military science fiction.

## Games

- **Lost Echos** — a sci-fi horror game in development in Godot, set in the Spirit Tamer universe. Aiming for a 2027 release on Steam and itch.io.
- **[Blender Godot Curve3D Exporter](https://github.com/jbmedlin/blender-godot-curve3d-exporter)** — a Blender add-on that exports Bezier curves as native Godot 4 Curve3D resources. Built for my own pathing work, open for anyone's.

## Books

- **[The War Devil](https://siliconabyss.com/books/the-war-devil-spirit-tamer-book-1/)** — grimdark military science fiction, published August 2024. Follows D, an Overman Agent, through a contract on the planet Verra.
- A second book in progress.
